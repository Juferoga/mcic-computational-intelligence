\section*{Declaración de uso de inteligencia artificial}
{\footnotesize 
Usé Claude Code (Anthropic, modelos Claude Opus) para proponer y escribir el código de minería, exploración y búsqueda bibliográfica (\texttt{src/}, \texttt{revision/}), para buscar y resumir artículos, y para redactar borradores de este informe. Usé Gemini (Google) para revisar y corregir la redacción. Verifiqué lo producido así: ejecuté el código y el cuaderno de principio a fin; todas las cifras del texto salen de macros generadas desde los archivos de resultados, sin copiarlas a mano; contrasté cada referencia con su DOI o URL; y revisé que las decisiones de diseño (etiqueta, censura, partición y modelos) correspondieran a lo que planteé en el Entregable 1.}
