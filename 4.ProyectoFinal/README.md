# LINEAMIENTOS GENERALES PROYECTO FINAL

En equipos de 1 o 2 personas, van a construir, entrenar y evaluar un modelo basado en un paradigma de inteligencia computacional (redes neuronales, sistemas difusos, computación evolutiva, enjambre o híbridos) para resolver un problema real con datos. El trabajo sigue la metodología CRISP-ML(Q) en ocho fases a lo largo de cinco semanas. Cada domingo se entrega un avance, y el proyecto cierra con un artículo en formato IEEE, el código reproducible y una sustentación oral. El documento adjunto trae las instrucciones de cada fase, el cronograma, los entregables y la rúbrica.

Fechas clave: entregables los domingos 8, 15, 22 y 29 de noviembre; entrega final el jueves 3 de diciembre; sustentación el viernes 4 de diciembre.
